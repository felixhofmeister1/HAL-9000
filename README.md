# HAL-9000

A conversational interface and backend integration inspired by HAL 9000, built with FastAPI, OpenAI, and Supabase for real-time messaging and state persistence.

## Tech Stack
- **Backend:** FastAPI, Python
- **Database/Persistence:** Supabase
- **AI Integration:** OpenAI API
- **Environment Management:** python-dotenv
